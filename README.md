# Test competențe directori 2026

Simulare interactivă a probei pentru evaluarea de competențe din cadrul concursului pentru ocuparea funcțiilor de director și director adjunct (13 octombrie 2026).

- 20 de itemi cu alegere multiplă, 0,50 puncte fiecare
- Cronometru de 60 de minute, cu predare automată la expirare
- Corectare pe baza baremului oficial, cu revizuirea fiecărui item
